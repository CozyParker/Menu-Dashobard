# Tutor Admin Dashboard

Tutor-facing admin dashboard built with Next.js 14 (App Router), TypeScript, Tailwind CSS, and shadcn-style components. The UI focuses on tutor ops and follow-through workflows with local mock data—no backend required.

## Getting started

```bash
npm install
npm run dev
```

The dashboard lives under the `/app/(dashboard)` route group and uses mock data in `lib/mock.ts`.

## Key features

- Today’s Command Center with pending queues, at-risk insights, and one-click actions
- Modules for cohorts, progress, homework, assessments, revision planning, visuals, gamification controls, projects, reports, automation, and tutor settings
- Responsive layout with desktop sidebar + mobile bottom nav and right-side insight panels
